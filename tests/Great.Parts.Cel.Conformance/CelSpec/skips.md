# cel-spec conformance skip list

Cases of the pinned cel-spec commit (tests/cel-spec/COMMIT) that may fail in the given scope. Every entry has a reason and, before a release, an issue. An entry is either a defect in the cel-spec test data that no implementation passes under the cel-go conformance rule, with a reference to the language definition or to a minimal case, or a difference by design of the library, with a minimal case. In release 1.0.0 the list could contain only defects in the test data.

| Case | Scope | Reason | Reference | Issue |
|---|---|---|---|---|
| network_ext/ip_type/is_ip_cidr_compile_error | * * * | Defect in the cel-spec test data. The case expects an evaluation error for isIP(cidr('192.168.0.0/24')), but the expression is ill-typed: isIP takes a string, so type checking rejects it under any implementation, and the conformance rule counts a type-check error as a failure. Reported to cel-spec as cel-expr/cel-spec#539 (https://github.com/cel-expr/cel-spec/issues/539). | Minimal case: expression isIP(cidr('192.168.0.0/24')), no variables, network extension version 1. Type checking reports no matching overload for 'isIP' applied to '(net.CIDR)', because isIP is declared only for string; the case sets disable_check: false, so the check runs and the expected evaluation error is never reached. | https://github.com/great-parts/great-parts-cel/issues/5 |
| wrappers/duration/max_value | * * * | By design, the library does not create google.protobuf.Duration as a message. The name is the type of a duration in the standard library, not a message type of the environment, so the literal google.protobuf.Duration{...} fails type checking with a not-a-type error, while the case expects a value or an evaluation error. A duration is created with duration(string), whose range is that of google.protobuf.Duration. | Minimal case: expression google.protobuf.Duration{seconds: 1}, no variables. Type checking reports that 'google.protobuf.Duration' is not a type; the case sets disable_check: false, so the evaluation that the case expects is never reached. | https://github.com/great-parts/great-parts-cel/issues/7 |
