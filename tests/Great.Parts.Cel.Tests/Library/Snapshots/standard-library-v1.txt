# The overloads of version 1 of the standard library, in the order of the table. A line is
# function | overload id | global or receiver | (parameter types, the receiver first) -> result type | dyn or - | five costs
# "dyn" marks an overload that is a candidate only when an argument has the static type dyn. The five costs are the units that a
# call charges on the probe arguments of size 0, 1, 10, 11 and 100: every string, bytes, list and map argument has that size at once,
# the pattern of matches is that many "a" too, a timestamp is 1970-01-01T00:00:00Z, a duration is 1s, any other argument is one fixed value.
# A line changes only by review: an identifier, a signature or a cost of a shipped version does not change.
